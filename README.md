# Радиальное меню поверх рабочего стола

## Запуск

```
npm install
npm start
```

## Управление

- По центру экрана — стеклянная кнопка с белой точкой. Клик — меню раскрывается кольцом, повторный клик — сворачивается.
- Центральную кнопку можно перетащить в любое место экрана.
- Клик по узлу — раскрывается его ветка вертикальной колонкой в сторону от центра. Соседняя открытая ветка закрывается сама.
- Зажать узел и тянуть — узел едет вместе со всей своей веткой, линии тянутся следом.
- Длинный список (больше 5 пунктов) переносится во вторую колонку, как у Figma в видео.
- Esc — свернуть меню, правая кнопка мыши — закрыть все открытые ветки разом.
- Иконка в трее — показать/скрыть или выйти.
- Ветка сама выбирает сторону: переворачивается, только если реально не влезает в экран и при этом не протащится через всё кольцо.
- Вложенная ветка отодвигается за колонки родителя, поэтому третий уровень не наезжает на второй.

## Кольцо

Внутреннее кольцо — 5 узлов через 72° от верхней точки, радиус 150:

| Узел | Код | Подпись |
|---|---|---|
| Контекст | по приложению | активное окно |
| Система | SYS | CPU 14% · RAM 57% |
| Связь | MSG | мессенджеры |
| Файлы | FS | C: свободно 108 Гб |
| Медиа | ♪ | тишина / исполнитель — трек |

Внешнее кольцо — 4 узла по диагоналям, радиус 253: Браузер (BR), Вкладки (TAB), Почта (@, с бейджем непрочитанных), Приложения (APP).

Под центром — кнопка поиска.

## Живые данные

Каждые 2 секунды подтягиваются загрузка процессора (по дельтам `os.cpus()`), занятая память, свободное место на системном диске, текущий трек и состояние моста с браузером. Счётчик писем обновляется раз в 30 секунд.

## Поиск приложений

Клик по лупе под центром разворачивает поле «Начни печатать для поиска». Результаты вылетают чипами справа, клик запускает приложение.

Индекс собирается из меню «Пуск» (Windows), `.desktop`-файлов (Linux) или `/Applications` (macOS) и обновляется раз в 5 минут. Иконки на Windows вытаскиваются через `ExtractAssociatedIcon` и кэшируются.

На время поиска окно временно становится фокусируемым — иначе ввод с клавиатуры в него не попадёт.

## Почта

Встроен минимальный IMAP-клиент без внешних зависимостей: логин, `SEARCH UNSEEN`, заголовки последних писем с декодированием `=?UTF-8?B?...?=`.

Скопируйте `mail.example.json` в `mail.json` рядом с `main.js` (или в папку данных приложения) и заполните:

```json
{
  "host": "imap.gmail.com",
  "port": 993,
  "tls": true,
  "user": "you@gmail.com",
  "pass": "пароль-приложения",
  "mailbox": "INBOX"
}
```

Для Gmail нужен пароль приложения, обычный пароль аккаунта IMAP не пустит. Пока файла нет, узел показывает «не настроена».

## Вкладки браузера

Приложение поднимает локальный мост на `127.0.0.1:7788`. Папка `browser-extension` — расширение, которое раз в 3 секунды отправляет туда список вкладок.

Установка: `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → выбрать папку `browser-extension`.

Пока расширение не установлено, узел честно показывает «браузер не подключён».

## Буфер обмена

Раздел «Буфер» хранит последние 8 скопированных текстов. Клик по записи кладёт её обратно в буфер и сразу отправляет Ctrl+V в активное окно — то есть вставляет в то приложение, с которым вы работаете.

## Активное приложение

Раз в 1.5 секунды определяется приложение в фокусе — его имя и логотип попадают в узел «Контекст», а ветка собирается под него.

24 встроенных профиля, и каждый разложен по подразделам — например, у Photoshop это Слои, Коррекция, Инструменты, Выделение, Трансформация, Файл и Просмотр, а внутри каждого — конкретные действия с горячими клавишами. У Figma — Инструменты, Объекты, Выравнивание, Просмотр, Панели. У редактора кода — Навигация, Правка, Поиск, Панели.

Список: Photoshop, Illustrator, Premiere Pro, After Effects, Lightroom, Figma, Blender, DaVinci Resolve, OBS, Unity, браузеры, редакторы кода, Word, Excel, PowerPoint, мессенджеры, Zoom/Teams, плееры, проводник, Notion/Obsidian, GIMP/Krita, AutoCAD, терминалы, Steam. Для всего остального — универсальный набор.

Клик по действию отправляет сочетание клавиш прямо в приложение. Окно меню нефокусируемое, поэтому фокус остаётся на приложении, а перед отправкой оно выводится вперёд.

Сочетания с Win и медиа-клавиши (пауза, следующий трек, громкость) отправляются через `keybd_event` — обычный `SendKeys` их не умеет. Остальное идёт через `SendKeys`, на macOS через `osascript`, на Linux через `xdotool`.

## Производительность

Раньше приложение само по себе подгружало систему в фоне, даже когда меню было свёрнуто:

- определение активного окна каждые 1.5 сек и трек плеера каждые 4 сек запускали **новый** `powershell.exe` и заново компилировали код через `Add-Type` — тяжёлая операция, плюс каждый новый процесс цепляет антивирус на проверку;
- движение мыши по всему экрану (окно растянуто на весь монитор) на каждое сырое событие делало проверку позиции и могло дёргать системный вызов, меняющий перехват кликов у окна — на мышах с высокой частотой опроса это сотни раз в секунду;
- дыхание центральной кнопки анимировало `box-shadow`, что каждый кадр перерисовывало заблюренный круг, пока приложение вообще запущено.

Сейчас:

- на Windows вместо запуска нового процесса на каждый опрос держится один долгоживущий `powershell.exe` — код компилируется один раз при старте, дальше опросы — это просто короткая команда в уже открытый процесс;
- проверка положения мыши ограничена одним разом за кадр отрисовки (через `requestAnimationFrame`), а не на каждое сырое движение;
- дыхание кнопки переведено на `transform`/`opacity` — это не требует перерисовки и почти ничего не стоит видеокарте;
- опрос активного окна снижен до раз в 2 сек, трека — раз в 5 сек.

## Разные системы

Окно растягивается по рабочей области текущего монитора, так что разрешение и масштаб подхватываются сами. Команды запуска описаны отдельно под каждую ОС:

```js
cmd: { win: 'taskmgr.exe', mac: 'open -a "Activity Monitor"', linux: 'gnome-system-monitor' }
```

Пути с `~` разворачиваются в домашнюю папку пользователя.

На Linux для определения активного окна и отправки клавиш нужен `xdotool`, для медиа-информации — `playerctl`:

```
sudo apt install xdotool playerctl
```

На macOS при первом запуске система попросит разрешение в «Настройки → Конфиденциальность и безопасность → Универсальный доступ».

## Свой профиль приложения

Добавьте запись в `APP_PROFILES` в `renderer/data.js`:

```js
{
  match: ['yourapp'],
  label: 'Ваше приложение',
  logo: 'yourapp.com',
  children: [
    { label: 'Дублировать', sub: 'Shift + D', keys: 'shift+d' }
  ]
}
```

`match` ищет подстроки в имени процесса и заголовке окна. `keys` — отправляемое сочетание. `mod` автоматически становится Ctrl на Windows и Linux и Cmd на macOS.

## Геометрия

Если захотите подвинуть кольцо, константы лежат в начале `renderer/renderer.js`:

```js
const INNER_RADIUS = 150;   // внутреннее кольцо
const OUTER_RADIUS = 253;   // внешнее кольцо
const SEARCH_OFFSET = 62;   // кнопка поиска под центром
const ROW_HEIGHT = 68;      // шаг строк в ветке
const ROWS_PER_COLUMN = 5;  // после скольких пунктов перенос в колонку
```
